# SWIGGY Android Studio starter

A small Kotlin companion-interface starter for Android 16.

## Open it
1. Extract the ZIP.
2. Open the `SWIGGY_Android_Studio` folder in Android Studio.
3. Allow Gradle sync to finish.
4. Connect your phone with USB debugging enabled, or use an emulator.
5. Press **Run**.

## Important scope
This is a companion dashboard only. It does not install KernelSU, grant root,
run privileged shell commands, hide root, alter app detection, or change
device-integrity / tournament-verification results. Use the official KernelSU
app for supported root and module management.

The orange visual style is an independent design and is not affiliated with
Swiggy or KernelSU.

## Build note
The project uses Android Gradle Plugin 8.10.1, Kotlin 2.1.20, and compile SDK 36.
Android Studio may ask to install Android SDK Platform 36.
